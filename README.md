# Smart Placement Dashboard — GitHub Pages

Restored original sample records from the Flask project while keeping the current static dashboard styling.

## Deploy
Upload/replace `index.html` and the `assets` folder in your repository root. GitHub Pages settings: Deploy from a branch → `main` → `/(root)`.

## Note
GitHub Pages is static hosting. These five sample profiles are embedded in JavaScript; adding a demo profile is temporary and does not save to a permanent database. Permanent shared saving requires a backend and database. Example emails are placeholders from the original sample data.
